# 10 接続キー（Microsoft Foundry・Azure Speech のキー）

外部サービスのキーは、画面の一番上の **［接続キー］** から開く「接続キー」画面で登録します。
［設定］（レイアウトと描画スタイルを選ぶ画面）とは別の画面です。

> この文書の例はすべてプレースホルダです。`<リソース名>` や `<キー>` は、ご自分の値に読み替えてください。実際のキーをこの文書やチャット・メールに書かないでください。

## 開き方と閉じ方

- 開く: 画面最上部のコマンドバーにある、鍵のアイコンの **［接続キー］**（説明文字「Microsoft Foundry・Azure Speech のキーを登録します」つき）を押します。キーボードでは Ctrl+Alt+Shift+H です。
- 画面の中央にダイアログが開き、背後の画面はグレーがかったオーバーレイで覆われます。開いている間、背後の操作はできません（記録・音声認識は止まらず、図も変わりません）。
- 閉じる: 右上の［閉じる］（×）、ダイアログ内の［閉じる］、または Esc キーです。閉じると、フォーカスは［接続キー］のボタンに戻ります。
- オーバーレイをクリックしても閉じません（入力中のキーを誤って失わないためです）。
- 閉じると、保存していない入力欄の値は破棄され、開き直しても復元されません。

## 画面の見かた

左に分類の一覧（**Microsoft Foundry**・**Azure Speech**）、右に選んだ分類の内容が並びます。分類は、クリックか、一覧にフォーカスして上下の矢印キーで切り替えます。画面が狭いときは、一覧と内容が縦に並びます。

## Azure Speech の分類の使い方

1. 分類の一覧で［Azure Speech］を選びます。
2. ［接続先］にエンドポイント（`https://<リソース名>.cognitiveservices.azure.com` かリージョン名）を入力します。
3. ［キー］に `<キー>` を入力します（入力中は伏せ字です）。
4. ［保存］を押します。保存の後、キーの欄は空に戻り、状態に「接続先:」のホスト名と「キー: 設定済み」が表示されます。
5. ［接続テスト］で、保存した内容で接続できるかを確かめられます。
6. キーを消すときは［削除］を押し、確認で［キーを削除］を選びます。

この分類で保存した内容は、［設定］画面の「Azure Speech（音声認識）」の項目と同じ保管先を共有するので、どちらで保存しても、もう一方の状態に反映されます。詳しい使い方は [09 Azure Speech](09-azure-speech.md) を見てください。

## Microsoft Foundry の分類の使い方

1. 分類の一覧で［Microsoft Foundry］を選びます。
2. ［キー］に `<キー>` を入力して［保存］を押します。保存の後は欄が空に戻り、状態が「キー: 設定済み」（出どころは「画面で保存」）になります。キーの値は二度と表示されません。設定済みのときに新しいキーを保存すると、置き換わります。
3. 削除は［削除］を押し、確認で［キーを削除］を選びます。環境変数・設定ファイルで設定したキーは画面から削除できません（その旨が表示されます）。
4. データの初期化（［データ初期化］）では、キーは消えません。キーを保存しても、LLM 連携は有効になりません（［設定］の LLM 連携の切り替えは別です）。

中継サーバーが応答していないときは、キーを変更できず、理由が表示されます。中継サーバー（`start.ps1` / `start.sh`）を起動してから開き直してください。
