# 06 トラブルシュート

[目次](README.md) ｜ 前: [05 言語切替・2D/3D・プレゼンテーション](05-language-and-views.md)

## 画面が開かない・動かない

- `index.html` を `file://` で開いていませんか。使えません。[01 導入と起動](01-getting-started.md)のとおり `python -m http.server -d web 8080` で起動し、<http://localhost:8080/> を開いてください。
- ポート 8080 が使用中のときは、別の番号（例: `8081`）に変えて起動し、URL の番号も変えてください。
- 画面が古いままのときは、ブラウザを再読み込みしてください。Service Worker が古い画面一式を保持している場合があります。

## 音声認識が使えない

最新版の Edge でも、日本語の音声認識は**デバイス内では動きません**。ステータス表示が「使えます（要同意・外部送信の可能性）」のときは、「認識文字列」パネルの「外部サービスでの音声認識に同意する」をオンにすると、ブラウザ提供元などの外部サービス経由で使えます。この場合、音声が外部へ送られる可能性があるので、機密性の高い内容では使わないでください（同意はこのページを開いている間だけ有効です）。

「使えません」と表示されたときは、続く理由を確認してください。

- 「このブラウザは音声認識（Web Speech API）に対応していないため、音声認識は使えません。」: Chrome / Edge など対応ブラウザを使ってください。
- 「選択中の言語は、このブラウザの音声認識が対応していないため使えません。」: 表示言語を切り替えるか、手入力を使ってください。
- 「音声認識の言語モデルを導入できなかったため、音声認識は使えません。」: ブラウザのフラグ設定（chrome://flags / dge://flags のオンデバイス音声認識に関する項目）と、言語モデルをダウンロードできる通信環境・空き容量を確認し、再度「音声認識を開始」を押してください。
- 「デバイス内で音声認識できないため、外部サービスに音声が送られる可能性への同意が必要です。」: 同意するか、手入力（[02 音声入力とファイル取込](02-voice-and-import.md)）またはテキストファイルの取り込みを使ってください。

「マイクの許可が得られないため音声認識を使えません。」と出るときは、ブラウザのサイト設定でマイクを許可してください。記録済みの内容は保持されています。「音声認識でエラーが発生しました。」と出たときも、記録済みの内容は保持されています。手入力で続けられます。

## 発話が追加されない

- 「記録を開始・再開してください」と出るときは、「記録を開始」または「再開」を押してください。
- 「入力が空です」と出るときは、文を入力してください。
- ファイルを取り込めないときは、`.txt` であること、1 MB 以下であること、空でないことを確認してください。

## 保存できない

- 「保存できる図がありません（シーンが 0 件です）。」と出るときは、先に発話を入力して図を作ってください（[04 保存](04-export.md)）。
- 「保存に失敗しました」と出るときは、ブラウザのダウンロードがブロックされていないかを確認してください。

## 3D 表示にならない

「3D 表示が使えない環境のため、2D 表示で代替します」と出るときは、WebGL が使えない環境です。2D 表示で利用してください（[05 言語切替・2D/3D・プレゼンテーション](05-language-and-views.md)）。

## 配置が崩れた・パネルが消えた

「既定のレイアウトに戻す」（`Alt + Shift + 0`）を押してください。非表示にしたパネルは「表示する」で戻せます。

通常のタイル配置では、画面上部の操作バーの下に「図」「テキスト一覧」「認識文字列」の 3 パネルが並び、ウィンドウの高さに合わせて表示されます。長い内容は各パネル内でスクロールします。狭い画面ではパネルが縦に並ぶため、ページをスクロールして確認してください。

操作バーが表示されない、または更新後もパネルが重なったままの場合は、ページを再読み込みしてください。古いオフラインキャッシュから表示されている場合は、更新が反映されてからもう一度再読み込みしてください。保存済みの記録を消す必要はありません。
