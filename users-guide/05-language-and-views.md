## 言語切替

「表示言語」グループの「日本語」「English」で、画面の表示言語を切り替えます（`Alt + Shift + J` / `Alt + Shift + K`）。ステータス表示の「言語」にも現在の言語が出ます。音声認識の言語も、表示言語に従います。

## 2D / 3D 表示

「表示」グループの「2D 表示」「3D 表示」で切り替えます（`Alt + Shift + D` / `Alt + Shift + V`）。3D 表示では、シーンが空間に配置されます。

3D 表示が使えない環境（WebGL が使えない場合）では、「3D 表示が使えない環境のため、2D 表示で代替します」と表示され、2D 表示になります。

## プレゼンテーション

「プレゼンテーション」グループで、シーンを順に見せることができます。

| ボタン | キー |
|---|---|
| 「プレゼン開始」 | `Alt + Shift + G` |
| 「プレゼン一時停止」 | `Alt + Shift + H` |
| 「プレゼン再開」 | `Alt + Shift + Y` |
| 「プレゼン停止」 | `Alt + Shift + T` |
| 「前のシーンへ」 | `Alt + Shift + ←` |
| 「次のシーンへ」 | `Alt + Shift + →` |

シーンがないときは「提示できるシーンがありません」と表示されます。OS の「動きを減らす」設定（`prefers-reduced-motion`）に従い、その設定のときは動きを抑えます。

## 配色・レイアウト・キー操作

- 「配色の切替（ダーク／ライト）」（`Alt + Shift + M`）で、ダークとライトを切り替えます。
- 「既定のレイアウトに戻す」（`Alt + Shift + 0`）で、パネルの配置と大きさを初期状態に戻します。
- すべての操作は `Alt + Shift + <キー>` で行えます。主なキーは次のとおりです。

| キー | 操作 | キー | 操作 |
|---|---|---|---|
| R | 「記録を開始」 | 1 / 2 / 3 | PNG / SVG / PDF で保存 |
| P / E | 「一時停止」/「再開」 | J / K | 日本語 / English |
| X | 「終了」 | D / V | 2D 表示 / 3D 表示 |
| N | 「次のシーン」 | G / H / Y / T | プレゼンの開始 / 一時停止 / 再開 / 停止 |
| I | 「入力欄へ移動」 | → / ← | プレゼンの次 / 前のシーン |
| S / W | 音声認識の開始 / 停止 | M | 配色の切替 |
| 0 | 「既定のレイアウトに戻す」 | | |
