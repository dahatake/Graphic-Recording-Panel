# 03 図の見方

[目次](README.md) ｜ 前: [02 音声入力とファイル取込](02-voice-and-import.md) ｜ 次: [04 保存](04-export.md)

## 図の見方

「図」パネルには、発話から自動で区切られた「シーン」が並びます。

- シーンは、見出し（色分けの帯）と要点（箇条）でできています。
- シーンの状態は「進行中」と「確定」で区別します。色だけでなく、記号と枠線の種類でも示すので、色が見分けにくくても分かります。
- 「モヤモヤ」「不安」「嬉しい」「アイデア」などの感情・様子を表す語があると、シーンに絵記号が付きます。
- 選択中のシーンは「選択中」と示されます。

「図」の表示を操作するボタンは「拡大」「縮小」「等倍に戻す」です。図の上では矢印キーでスクロールできます。

## 要点の強調（演出）

図の中の要点を、順に目立たせて指し示せます。強調は表示だけの状態で、保存や書き出しの内容は変わりません。色だけでなく、枠線などの形でも示されます。

| 操作 | キー（コマンドバーにも同名のボタン） |
|---|---|
| 「次の要点を強調」 | `Alt + Shift + ↓` |
| 「前の要点を強調」 | `Alt + Shift + ↑` |
| 「強調を解除」 | `Alt + Shift + Esc` |

## 整理の表示（縦軸・横軸の区分）

コマンドバー（またはキー）で、図の見せ方を切り替えられます。

- 「整理の表示（軸と区分）」（`Alt + Shift + A`）: 縦軸・横軸の区分（例: 論理層→物理層 × ワークフロー／部署のステップ）に要点やシーンを並べます。軸の名前・区分の見出し・「未分類」の領域は文字で示されます。
- 「時系列の表示」（`Alt + Shift + Q`）: 元の時系列の並びに戻します。

強調した要点は、`Ctrl + Alt + Shift + ↑ / ↓ / ← / →` で、上・下・左・右の区分へ移せます（コマンドバーの「選択中の要点を上の区分へ」などのボタンでも同じです）。「テキスト一覧」には、整理の表示でも時系列の順序のまま、軸・区分の説明が文字で添えられます。保存（PNG・SVG・PDF）は、画面で選んでいる表示と同じ配置で出力されます。

## テキスト一覧

「テキスト一覧」には、図と同じ順序でシーンと要点がテキストで並びます。画面読み上げ（スクリーンリーダー）でも、図と同じ情報を確認できます。まだシーンがないときは「まだシーンがありません」と表示されます。

## 図の手修正

「図の手修正」（テキスト一覧の下のフォーム）で、自動で作られた図を直せます。

- 「対象の要点」を選び、「要点の文」を書き換えて「編集を反映」を押すと、要点を修正できます。
- 「削除」で要点を削除します。
- 「要点を追加」で要点を追加します。
- 「次のシーンと結合」で、次のシーンとまとめます。
- 「ここからシーンを分割」で、選んだ要点からシーンを分けます（先頭の要点では分割できません）。

「次のシーン」（`Alt + Shift + N`）を押すと、次のシーンを始められます。
