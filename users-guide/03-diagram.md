# 03 図の見方

## 図の見方

「図」パネルには、発話から自動で区切られた「シーン」が並びます。

- シーンは、見出し（色分けの帯）と要点（箇条）でできています。
- シーンの状態は「進行中」と「確定」で区別します。色だけでなく、記号と枠線の種類でも示すので、色が見分けにくくても分かります。
- 「モヤモヤ」「不安」「嬉しい」「アイデア」などの感情・様子を表す語があると、シーンに絵記号が付きます。
- 選択中のシーンは「選択中」と示されます。

「図」の表示を操作するボタンは「拡大」「縮小」「等倍に戻す」です。図の上では矢印キーでスクロールできます。

## テキスト一覧

「テキスト一覧」には、図と同じ順序でシーンと要点がテキストで並びます。画面読み上げ（スクリーンリーダー）でも、図と同じ情報を確認できます。まだシーンがないときは「まだシーンがありません」と表示されます。

## 図の手修正

「図の手修正」（テキスト一覧の下のフォーム）で、自動で作られた図を直せます。

- 「対象の要点」を選び、「要点の文」を書き換えて「編集を反映」を押すと、要点を修正できます。
- 「削除」で要点を削除します。
- 「要点を追加」で要点を追加します。
- 「次のシーンと結合」で、次のシーンとまとめます。
- 「ここからシーンを分割」で、選んだ要点からシーンを分けます（先頭の要点では分割できません）。

「次のシーン」（`Alt + Shift + N`）を押すと、次のシーンを始められます。
