# 07 新機能の使い方（ラベル・初期化・ファイル保存・3D の評価軸と操作）

[目次](README.md) ｜ 前: [06 トラブルシュート](06-troubleshooting.md)

## コマンドバーのラベルの見方

コマンドバーのボタンは、アイコンの下に短い名前（ラベル）が常に表示されます。マウスを重ねなくても、何のボタンか分かります。

- ラベルは 1〜2 行で表示され、横にスクロールせずに全体が見えます。
- 表示言語を切り替えると、ラベルもすぐに切り替わります（例: 「記録開始」⇔「Record」）。
- ボタンにマウスを重ねたりフォーカスを合わせたりすると、操作の説明（ツールチップ）も出ます。
- 主なラベル: 「記録開始」「一時停止」「再開」「記録終了」「次シーン」「入力」「PNG保存」「SVG保存」「PDF保存」「2D表示」「3D表示」「時系列」「整理」「配色」「発表開始」「タイル」「集中」「最大化」「配置初期化」「データ初期化」「ファイル保存」「ファイル読込」。

## データの初期化

「データ初期化」ボタンで、議論の内容を消して、はじめの状態に戻せます。

1. 「データ初期化」を押すと、確認のダイアログが開きます。
2. 消えるのは、発話・認識文字列・シーン・要点・図の手修正・整理の割り当てと、ブラウザ内に自動保存されたセッションです。
3. 「初期化する」を押すと実行されます。やめるときは「キャンセル」を押します。
4. 初期化は**元に戻せません**。必要な内容は、先に「ファイル保存」で残してください。

レイアウト・表示言語・テーマ（配色）は、初期化しても変わりません。初期化が終わると「データを初期化しました。記録は準備中です」と表示されます。

## セッションファイルの保存と読込

議論の途中のデータを、ファイルとして保存・読込できます。

### ファイル保存

「ファイル保存」ボタンで、議論の途中のデータを 1 つのセッションファイル（`grp-session-<日時>.json`）として端末に保存します。保存できたときは「セッションファイルを保存しました」と表示されます。発話がまだないときは「保存できるデータがありません。発話を記録してから保存してください」と表示されます。外部へは送信されません。認識文字列もこのファイルに保存されます（音声データは保存されません）。

### ファイル読込

1. 「ファイル読込」ボタンを押し、保存したファイルを選びます。
2. 現在のデータがあるときは、確認のダイアログが出ます。「置き換えて読み込む」で、現在のデータは読み込む内容に置き換えられて消えます（元に戻せません）。
3. 読み込むと「セッションファイルを読み込みました。一時停止中です。再開すると記録を続けられます」と表示されます。**読込後は一時停止**です。「再開」を押すと記録を続けられます。

読めないファイルのときは、理由（大きすぎる・JSON ではない・セッションファイルではない・版が合わない・内容が壊れている）が表示され、現在のデータはそのままです。

### ブラウザへの自動保存との違い

[04 保存](04-export.md) のブラウザへの自動保存（見出し）は、利用中のブラウザの中だけに、発話とシーンなどを自動で残す機能です。認識文字列は含まれず、ブラウザのサイトデータを消すと消えます。「ファイル保存」は、自分で操作して、認識文字列も含めて端末にファイルとして残す機能です。別の端末への持ち運びや、バックアップに使えます。

## 3D の評価軸の選び方

「3D表示」にすると、3D の評価軸の選択（「横」「縦」「奥行き」）が表示されます。シーンの位置は、選んだ軸の値で決まります。はじめは、横=「要点の数」、縦=「感情の強さ（感情語の数）」、奥行き=「時間（シーンの発生順）」です。

選べる軸は次の 7 種類です。

- 「時間（シーンの発生順）」
- 「要点の数」
- 「発話量（文字数）」
- 「感情の強さ（感情語の数）」
- 「要点の種類ごとの数」（結論・課題・アイデア・補足）
- 「整理の縦軸の区分」
- 「整理の横軸の区分」

### 選べない軸

- 今の議論から値が得られない軸は、「選べません」と表示され、選べません。理由も表示されます（例: 「全シーンで値が同じため選べません」「整理の割り当てがないため選べません」）。
- 同じ軸を 2 つの方向には選べません（別の方向で選択中のときはその旨が表示されます）。
- はじめの軸のうち値が得られないもの（例: シーンが 1 件のときの「時間」、感情語が 0 件のときの「感情の強さ」）は、別の軸に置き換わりません。そのまま「選べません」と理由が表示されます。データ初期化やファイル読込のあとも同じです。シーンが増えて値が得られるようになると、選べるようになります。
- 「整理の縦軸の区分」「整理の横軸の区分」は、「整理」で図形に区分を割り当てると選べるようになります（[03 図の見方](03-diagram.md)）。

軸を変えると、配置がすぐに更新されます。選んでいるシーンはそのまま保たれ、記録中でも変更できます。画面には、軸ごとの目盛り・区分と、各シーンの軸の値の一覧も表示されます。

## 3D の画面操作と操作説明

3D 表示の下部に「3D 表示の操作方法」が表示され、マウス・タッチ・キーボードでの操作が一覧になっています。

| 操作 | マウス | タッチ | キーボード |
|---|---|---|---|
| 回転 | ドラッグ | 1 本指でドラッグ | `Ctrl + Alt + Shift + J / L / I / K`（左 / 右 / 上 / 下） |
| 拡大縮小 | ホイール | 2 本指でピンチ | `Ctrl + Alt + Shift + E / Q`（拡大 / 縮小） |
| 移動 | Shift を押しながらドラッグ | 2 本指でドラッグ | `Ctrl + Alt + Shift + A / D / W / S`（左 / 右 / 上 / 下） |
| 視点を初期に戻す | 「視点を初期に戻す」ボタンをクリック | 「視点を初期に戻す」ボタンをタップ | `Ctrl + Alt + Shift + R` |

- 画面が狭いときは、操作説明が短い形で表示されます。
- 操作の対象は視点だけで、シーンの内容は変わりません。
