# 01 導入と起動

[目次](README.md) ｜ 次: [02 音声入力とファイル取込](02-voice-and-import.md)

## 導入（必要なもの）

- Chrome または Edge の最新版（推奨）
- Python 3.7 以上（静的サーバーの起動に使います。Python 以外の静的サーバーでもかまいません）
- ビルドやインストールは不要です。リポジトリを取得するだけで使えます。
- 外部のサーバー・CDN への通信は一切ありません。

## 起動

リポジトリのルートに Windows 用の `start.ps1` と macOS 用の `start.sh` があります。

**Windows（PowerShell）**
```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

**macOS（ターミナル）**
```sh
sh ./start.sh
```

ブラウザで <http://localhost:8080/> を開くと、「グラフィックレコーディング パネル」が表示されます。

起動したターミナルは開いたままにしてください。終了するときは `Ctrl+C` を押します。サーバーはこの PC 内からだけ接続できる `127.0.0.1:8080` で動作します。ポート 8080 が使用中というエラーが出た場合は、そのポートの使用を終了してから再実行してください。

別のフォルダーから実行するときはスクリプトの絶対パスを指定してください。スクリプトが置かれた場所の `web/` が配信されます。追加パッケージのインストールや実行権限の付与は不要です。

`web/index.html` をダブルクリックして `file://` で開く方法は使えません。ブラウザが `file://` からの ES モジュールの読み込みと Service Worker の登録を拒否するためです。必ず `localhost` 経由で開いてください。

## 画面の構成

- 画面上部の「操作」バー（コマンドバー）: 作業の順に、左から「取り込み」「記録」「表示」「レイアウト型」「プレゼンテーション」「図の書き出し」「データ」「画面・環境」の 8 つの見出し付きグループにボタンが並びます（データの初期化は「データ」の末尾）。
- コマンドバーの下のステータス表示: 「記録の状態」（準備中・記録中・一時停止中・終了）、音声認識が使えるか、言語、表示（2D / 3D）が出ます。
- 3 つのパネル:
  - 「認識文字列」（右パネル）: 入力した発話・取り込んだ発話の一覧と、発話の入力欄、ファイルの取り込み
  - 「図」: グラフィックレコーディング風の図
  - 「テキスト一覧」: 図と同じ順序のテキスト。画面読み上げでも同じ内容を確認できます

各パネルの見出しの横のメニュー「パネルの操作」から、「左へ移動」「右へ移動」「上へ移動」「下へ移動」「大きくする」「小さくする」「非表示にする」「最大化」「元の大きさに戻す」ができます。非表示にしたパネルは「表示する」で戻せます。「既定のレイアウトに戻す」で初期配置に戻ります。

## 最初の一回

1. 「記録を開始」を押します（または `Alt + Shift + R`）。
2. 「発話を入力」の入力欄に文を書き、「送信」を押します。
3. 「図」と「テキスト一覧」に、シーン（見出しと要点）が追加されます。

## オフライン動作

初回表示のあと、Service Worker（`web/sw.js`）が画面一式を保存します。以降はネットワークを切断しても起動できます。画面が古いままのときは、ブラウザの更新（再読み込み）をしてください。
