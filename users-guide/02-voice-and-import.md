# 02 音声入力とファイル取込

[目次](README.md) ｜ 前: [01 導入と起動](01-getting-started.md) ｜ 次: [03 図の見方](03-diagram.md)

発話は、手入力・音声入力・ファイル取込のどれでも追加できます。いずれも、先に「記録を開始」（または「再開」）をしておく必要があります。記録していないときは「記録を開始・再開してください」と表示されます。

## 手入力

「認識文字列」パネルの「発話を入力」に文を書き、「送信」を押します。`Alt + Shift + I`（「入力欄へ移動」）で入力欄へ移動できます。空のまま送ると「入力が空です」と表示されます。

## 音声入力

「音声認識を開始」を押す（または `Alt + Shift + S`）と、マイクの音声を文字にして発話として追加します。「音声認識を停止」（`Alt + Shift + W`）で止めます。

- 選択中の言語がブラウザの**デバイス内**で認識できるときは、そのまま使えます（同意は不要で、音声は外部へ送られません）。言語モデルが未導入でも導入できる場合は、開始時に自動で導入してから使います。
- デバイス内で認識できない言語（最新版の Edge では日本語がこれに当たります）でも、ブラウザが音声認識に対応していれば、「外部サービスでの音声認識に同意する」をオンにした後に限って使えます。この場合、**音声がブラウザ提供元などの外部の音声認識サービスへ送られる可能性**があります。機密性の高い内容では同意せず、手入力かファイル取込を使ってください。同意は既定でオフで、このページを開いている間だけ有効です（再読み込みで未同意に戻ります）。同意をオフにすると認識は止まります。同意の切替はキーボード（Alt + Shift + C）でもできます。いずれの場合も、音声データはこのアプリでは保存しません。
- 使える状態かどうかは、ステータス表示の「使えます（デバイス内）」「使えます（要同意・外部送信の可能性）」「使えません」で分かります。「使えません」のときは理由（非対応のブラウザ・言語未対応・言語モデル未導入・マイク未許可）が続けて表示されます。
- 認識の途中の文字は「認識中（未確定）」として表示されます。確定したものは「認識文字列」の一覧に「確定」として並びます。
- 音声認識の言語は、現在の表示言語（日本語 / English）に従います。可否は選択中の言語だけで判定します（日本語が使えなくても English は使えることがあります）。
- 初回はブラウザがマイクの許可を求めます。許可しないと使えません。

使えないときは、手入力かファイル取込を使ってください（[06 トラブルシュート](06-troubleshooting.md)）。

## ファイル取込

「テキストファイル（.txt）・字幕ファイル（.vtt）を取り込む」からテキストファイルまたは字幕ファイル（WebVTT。Teams の文字起こしなど）を選ぶと、内容が発話として取り込まれ、「ファイルから発話を取り込みました」と表示されます。字幕ファイルでは、話者名とタイムスタンプは取り込まれず、発話の文章だけが追加されます。

- 取り込めるのは `.txt` のテキストファイルだけです。上限は 1 MB です。
- 大きすぎる、テキストではない、空のファイルは、理由が画面に表示されて取り込まれません。
- 取り込んだ内容は、ブラウザの中だけで処理されます。外部へは送信されません。
