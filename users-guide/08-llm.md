# 08 LLM 連携（方式2・任意）の使い方

LLM 連携は任意の機能で、**既定はオフ**です。オフのままでも、これまでの機能（方式1）はすべてそのまま使えます。LLM 連携は、同じパソコンで動くローカルの中継サーバー（`start.ps1` / `start.sh` で起動）が、設定した Microsoft Foundry のエンドポイントへ中継して行います。API キーやトークンはブラウザーには渡りません。

## 1. 設定する項目

| 項目 | 環境変数 | 設定ファイルの項目 | 内容 |
|---|---|---|---|
| エンドポイント | `LLM_ENDPOINT` | `endpoint` | https の公開ホストの URL だけ使えます（localhost・内部のアドレスは拒否されます） |
| デプロイ名 | `LLM_DEPLOYMENT` | `deployment` | Foundry でのモデルのデプロイ名 |
| 認証方式 | `LLM_AUTH_METHOD` | `authMethod` | `apiKey`（既定）または `entra` |
| API キー | `LLM_API_KEY` | `apiKey` | 認証方式が `apiKey` のときだけ必要 |

### 設定の置き場所
- **環境変数**で設定する、または、git 管理外の **`config/llm.local.json`** に書きます。書式は秘密を含まない [config/llm.example.json](../config/llm.example.json) をコピーして確認してください（`config/llm.local.json` は `.gitignore` に載っており、コミットされません）。
- 両方にあるときは、**環境変数が優先**されます。設定は要求のたびに読み直されます。
- API キーを文書・コミット・チャットに書かないでください。

## 2. 2 つの認証方式
1. **API キー**（`apiKey`）: Foundry で発行したキーを `LLM_API_KEY` か `config/llm.local.json` の `apiKey` に設定します。
2. **Microsoft Entra ID**（`entra`）: 中継サーバーが `az account get-access-token`（スコープ `https://ai.azure.com/.default`）でトークンを取得します。事前に Azure CLI を導入し、`az login` でサインインしてください。キーの設定は不要です。

## 3. 同意と送信内容・既定オフと自動復帰
- LLM 連携は設定画面で有効にしたときだけ働きます。有効にするとき、送信される内容の説明が示され、同意が必要です。
- 送られるのは、要点の文字（簡易マスキング後）・シーン番号・描画スタイル名・部品キーの候補一覧だけです。会話の原文・音声・ファイル全文・セッションファイル・端末やブラウザの情報は送られません。直近 1 回分の送信内容は確認でき、無効にすると消えます。
- 簡易マスキングは既定で有効です（登録語・敬称付きの人名・メール・電話番号を伏せ字にします。完全な個人情報の除去は保証しません）。設定画面の「llm.mask」の項目で、Enter キーにより切り替えられます。
- 同意は、同意の事実・送信内容の版・同意日時だけをこのブラウザのローカル設定に保存します（API キー・会話内容は保存せず、セッションファイルやエクスポートにも含めません）。再読み込みしても同意は保たれます。送信内容の版が変わると再同意が必要です。設定画面で無効にすると同意は取り消され、再び有効にするには同意が必要です。
- 設定が不完全・取得失敗などで使えないときは、理由（秘密を含まない）が示され、連携はオフのまま、従来の描画が使われます。問題が解消すれば再び有効にできます。

## 4. 方式2（LLM による図の生成）
有効にすると、LLM が生成した SVG が安全な形に整えられて図に挿入されます。無効のときや失敗したときは、方式1（現行の描画）のままです。

## 5. トラブルの対処
| 症状 | 対処 |
|---|---|
| 連携が有効にならない | エンドポイント・デプロイ名・認証方式が設定されているか、エンドポイントが https の公開ホストか確認します |
| `az` が見つからない／サインインが必要と表示される | Azure CLI を導入し、`az login` を実行します |
| 設定ファイルを読み込めない | `config/llm.local.json` が [config/llm.example.json](../config/llm.example.json) の書式の JSON か確認します |
| 設定を変えても反映されない | 環境変数が設定ファイルより優先されます。環境変数の値を確認します |
