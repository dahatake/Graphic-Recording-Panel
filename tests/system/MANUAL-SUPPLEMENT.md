# System Test の補足（実ブラウザでの手動確認）

node:test の System Test は純粋モジュールと注入で検証するため、次の実ブラウザ固有の部分は手動で確認する（要求定義書の検証レベルは system のままで、自動ケースが主の判定。ここは補足）。

| AC | 確認 |
|---|---|
| AC-013 | PNG を保存し、画像ビューアで開けて、全シーンの見出しと要点が読める |
| AC-015 | PDF を保存し、PDF ビューアで開けて、全シーンの見出しと要点が読める |
| AC-016 / AC-031 | DevTools の Network で、操作中の同一オリジン以外へのリクエストが 0 件 |
| AC-032 | ネットワークを切断（機内モード）して、起動・手入力・図・2D/3D・PNG/SVG/PDF 保存が動く |
| AC-020 | 実 WebGL で 3D が奥行き表示され、選択シーンが保たれる |
| AC-025〜027 | ドラッグでの移動・リサイズ、メニュー・キーボードでの同等操作、再読込での復元 |
| AC-036 | マウスなしで、Tab とショートカットだけで全操作ができ、フォーカスが見える |
| AC-049 / AC-052 | 実ブラウザで、右パネルが図の右にあり、暫定結果が確定結果と見た目（色・字体・斜体など）で区別でき、スクリーンリーダーで「暫定」と読まれる |
| AC-053 / AC-054 | 実際の音声認識・手入力・ファイル取込で、図が 3 秒以内に更新されるのを目視（大きなファイルの負荷を含む） |
| AC-057 | Tab 順が操作の順序として自然で、フォーカスの輪郭がライト・ダーク・ハイコントラストで見える |
| AC-060 | コマンドバーが画面上部にあり、状態の変化がスクリーンリーダーで読み上げられる |
| AC-061 | DevTools の Network で、全画面の使用中にフォント・スタイル・スクリプトの外部取得が 0 件。実際の書体が Segoe UI（Windows）で描画される |
